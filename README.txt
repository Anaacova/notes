ЗАПИСНАЯ КНИЖКА — установка на Android

Это приложение работает в браузере и ставится на телефон как обычное (PWA).
Все записи хранятся только на вашем устройстве.

1. Разместите папку на любом хостинге с HTTPS (без этого установка не работает).
   Бесплатный вариант — GitHub Pages:
   • создайте репозиторий на github.com;
   • загрузите в него все файлы из этой папки (index.html, manifest.webmanifest, sw.js и папку icons);
   • Settings → Pages → Deploy from a branch → main / root;
   • через минуту-две появится адрес вида https://ваше-имя.github.io/название-репозитория/
   Другой вариант — Netlify Drop (перетащить папку в окно сайта).

2. Откройте этот адрес на телефоне в Chrome.
3. Меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
   Названия пунктов могут немного отличаться.
4. Откройте один раз с интернетом: после этого приложение работает без сети.

ВАЖНО
• Записи живут только в этом приложении на этом телефоне. Не реже раза в неделю
  делайте «Ещё → Резервная копия» и сохраняйте текст в надёжное место.
• Не меняйте адрес сайта после установки: у нового адреса будут пустые записи.
• Если выложите обновлённый index.html, при следующем открытии приложение
  подтянет его само (иногда нужно открыть приложение дважды).
